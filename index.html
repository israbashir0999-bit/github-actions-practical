Git Commands and Merge Conflicts

Introduction

This project demonstrates basic Git commands.

Git Commands

  • git add: Stages changes.
  • git commit: Saves staged changes in Git history.
  • git push: Uploads commits to GitHub.

Merge Conflict

A merge conflict occurs when Git cannot automatically combine changes from different branches.

Resolution

Review both changes, choose or combine the correct content, remove conflict markers, and commit the fix.
